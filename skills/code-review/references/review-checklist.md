# 通用审查清单

对每个审查类别，从变更和影响链出发检查。无关项目标记 N/A；不要为了填满清单制造问题。

## A. 功能正确性与业务逻辑（必查）

- 条件分支、状态机、业务规则、计算公式、排序/过滤和状态转换是否正确。
- 空值、缺省值、边界值、极端输入、时区、精度、溢出和编码问题。
- 循环、递归、分页、重试、幂等和重复提交行为。
- 异常路径、提前返回、资源释放及失败后的状态一致性。
- 是否破坏既有行为、兼容性或隐含业务约束。

## B. API、类型与模块契约（必查）

- 函数签名、类型、可空性、默认值、返回值和错误语义是否一致。
- REST/GraphQL/RPC API、事件、消息、回调及第三方集成契约是否兼容。
- 请求/响应 schema、序列化、反序列化、版本协商和字段演进。
- 公共接口、导出符号、SDK 行为及调用方是否同步更新。
- 类型断言、忽略类型检查、动态类型或不安全转换是否掩盖真实错误。

## C. 数据库、缓存与数据一致性（涉及数据时必查）

- Schema、migration、索引、约束、默认值、回滚和数据兼容性。
- SQL/ORM 查询正确性、N+1、分页、锁、事务边界和隔离级别。
- 并发写入、重复消费、幂等、最终一致性和缓存失效。
- 数据删除、隐私数据保留、租户隔离、备份恢复和数据迁移风险。
- 新旧版本程序并存时，读写格式和部署顺序是否兼容。

## D. 安全与隐私（必查）

- 输入验证、输出编码、SQL/NoSQL/命令/模板注入、XSS、路径穿越和 SSRF。
- 身份认证、授权、资源所有权校验、越权访问、租户隔离和权限默认值。
- CSRF、CORS、请求伪造、开放重定向、文件上传/下载和不安全反序列化。
- 密钥、Token、个人信息、日志、错误信息和调试接口泄露。
- 密码学算法、随机数、密钥存储、TLS、签名和证书校验。
- 依赖供应链、危险默认配置、容器权限、CI Secret 和部署暴露面。
- 速率限制、资源耗尽、滥用防护和拒绝服务风险。

## E. 并发、异步与可靠性（涉及异步/分布式时必查）

- Race condition、死锁、锁粒度、共享状态和事件顺序。
- Promise/Future、async/await、取消、超时、上下文传播和异常丢失。
- Goroutine/线程/任务泄漏、连接池耗尽、背压和队列堆积。
- 重试风暴、退避策略、幂等键、重复消息、消息顺序和死信处理。
- 分布式事务、部分失败、熔断、降级、限流和故障恢复。
- 文件、网络连接、锁、事务和其他资源是否在所有路径正确释放。

## F. 性能与资源（必查）

- 算法复杂度、重复计算、不必要遍历/复制、内存增长和大对象处理。
- 数据库访问次数、批处理、索引、缓存命中和网络往返。
- 同步阻塞、主线程阻塞、无界并发、连接池和资源上限。
- 启动时间、构建体积、首屏/渲染性能及关键路径延迟（适用时）。
- 缓存一致性、缓存击穿/雪崩和过期策略。

## G. 架构、可维护性与依赖（必查）

- 模块职责、依赖方向、循环依赖、层次边界和跨层访问。
- 业务逻辑是否被错误放入 UI、Controller、Infrastructure 或共享工具层。
- 抽象是否合理，是否造成不必要耦合、重复实现或过度复杂化。
- 配置、依赖版本、锁文件、弃用 API、许可证和运行时兼容性。
- 插件扩展点、公共包、向后兼容和模块边界是否被破坏。
- 错误处理、日志、指标、追踪和审计是否足以定位新故障。

## H. 测试与质量保障（必查）

- 是否为新行为、修复路径和关键边界增加/更新测试。
- 是否覆盖成功、失败、异常、权限、并发和回归场景。
- 测试是否验证行为，而非只验证实现细节或 mock 自身。
- 测试隔离、时间依赖、随机性、清理逻辑和环境依赖是否可靠。
- 测试、lint、typecheck、构建或静态扫描是否失败；失败是否由本次变更引入。
- 不因新增测试就默认功能正确，仍需独立检查实现。

## I. 前端与 UI（项目包含 UI 时）

- 组件状态、生命周期、Hooks 规则、状态同步和竞态更新。
- SSR/CSR、hydration、服务端/客户端边界、路由和缓存行为。
- XSS、危险 HTML、DOM 注入、前端权限误用和敏感数据暴露。
- 表单验证、重复提交、加载/空/错误状态和无障碍访问。
- 键盘操作、语义化、焦点管理、响应式布局和国际化。
- 包体积、懒加载、渲染次数、列表 key、图片和资源加载。

## J. 平台、构建与部署（涉及环境/基础设施时）

- 环境变量、配置优先级、Secret 注入、默认值和配置漂移。
- Linux/macOS/Windows 差异、路径/大小写/换行符、权限和信号处理。
- Docker 镜像、用户权限、健康检查、端口、卷、网络和多阶段构建。
- Kubernetes 资源、探针、权限、Secret、滚动更新和资源限制。
- CI/CD 权限、触发条件、缓存、制品来源、发布/回滚和迁移顺序。
- Terraform/IaC 资源变更、状态、权限范围、销毁风险和环境隔离。
